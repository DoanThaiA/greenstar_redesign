# Image Assets Directory

Place your hero and section background images here.

## Required Files

| File | Usage | Recommended Size |
|------|-------|-----------------|
| `hero-bg.jpg` | Hero section background | 1920 × 900px |
| `cta-bg.jpg` | CTA banner subtle overlay | 1920 × 600px |
| `about-farm.jpg` | About gallery – farm photo | 800 × 600px |
| `about-factory.jpg` | About gallery – factory photo | 800 × 600px |
| `about-team.jpg` | About gallery – team photo | 800 × 600px |
| `about-export.jpg` | About gallery – export photo | 800 × 600px |

All images can also be set from **WordPress Admin → Appearance → Customize → GreenStar Theme Options → Hero Section**.
